# lanshu-waytovideo 项目分析（面向即梦网页版迁移）

目标仓库：`https://github.com/cclank/lanshu-waytovideo/tree/main`

## 1. 原项目定位

该项目核心是一个基于 Playwright 的网页自动化视频生成 Skill，重点场景包括：
- 文生视频（T2V）
- 图生视频（I2V）
- 参考视频生成（V2V）
- 自动下载成片

## 2. 可迁移的核心架构

适合复用到即梦网页版的能力：
1. **浏览器会话复用 + Cookie 登录**
2. **参数化生成（模型、比例、时长、Prompt）**
3. **轮询生成状态并下载**
4. **对生成结果进行自动校验（时长/分辨率/src 变化）**

## 3. 迁移到即梦网页版的关键差异

1. **UI 文案差异**：按钮/下拉可能是“立即生成”“模型”“比例”“时长”等中文标签。
2. **DOM 结构差异**：需要通过更稳健的 selector 兜底。
3. **下载链路差异**：即梦有可能是按钮触发下载，也可能是详情页资源地址，需要双策略。

## 4. 当前仓库已完成的适配方向

- 将默认平台语义从 Seedance 调整为 Jimeng Web。
- 增加面向中文界面的 selector 兜底。
- 保留旧 planner 命名的兼容别名，减少调用方改造成本。

## 5. 建议的下一步

1. 在真实即梦页面录制一次 Playwright trace，固化稳定 selector。
2. 加一组“页面契约测试”验证关键控件可发现。
3. 对下载链路做 fallback（按钮下载失败时转抓取链接）。
